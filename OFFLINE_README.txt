异境回响 · 完整离线包

1. 把整个 ZIP 解压到你选择的文件夹。不要直接在压缩包里运行，也不要双击 index.html。
2. 电脑需要预先安装 Python 3 或 Node.js，任选其一。包内没有捆绑运行时，不会自动安装软件。
3. Windows：双击 START_OFFLINE.cmd。它只在本机启动服务器，并打开游戏页面。
   macOS / Linux：在解压目录运行 python3 start-offline.py 或 node start-offline.mjs。
4. 浏览器打开 http://127.0.0.1:8897/play.html 即可。保留启动窗口；退出时按 Ctrl+C。
   如果提示端口占用，先关闭之前打开的本地游戏服务器，再启动一次。

完整包包括角色、地图、音效、音乐和 Three.js；准备好运行时后，无需外网。
启动脚本仅监听本机，不把游戏开放到局域网。支持 WebGL 的现代浏览器仍是必要条件。

手机可以保存 ZIP 作为备份，但多数手机浏览器不能直接运行解压后的网页模块。
手机推荐在在线游戏的“下载 / 离线”中保存到本浏览器，完成后添加到主屏幕，再断网游玩。

游戏记录仍保存在浏览器，未打包进 ZIP。在线网址与本机网址是不同来源，存档不会自动互通。
更新离线包时完整解压到新目录，关闭旧服务器后启动新版；继续使用同一浏览器与上述固定地址。
不要清理浏览器的网站数据。移动游戏文件夹不会把浏览器存档一起复制给别人。

THIRD_PARTY_ASSETS.md 列出素材许可与来源。
