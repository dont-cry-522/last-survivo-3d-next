# 林地远征 3D NEXT · 林心回响

一款可切换第一人称与第三人称、自由转动视角的 3D 生存冒险网页游戏。在森林、雪地、灰烬、沙漠与海港中探索，选择武器与成长路线，迎战各地守卫。

[开始游戏](https://dont-cry-522.github.io/last-survivo-3d-next/play.html) · [角色与技能资料](docs/设计参考/README.md) · [完整更新记录](docs/更新记录.md)

从[原版 v114](https://github.com/dont-cry-522/last-survivo-3d/tree/1dd7466fc82e48a98e266d09df49a5de1fce967f)复制的独立开发版本，保留完整提交历史与游戏资源。后续开发在本仓库进行；[原版网址](https://dont-cry-522.github.io/last-survivo-3d/play.html?v=114)继续保留。两个版本的存档、偏好设置与离线缓存相互独立。

## 游玩内容

- 7 位英雄、13 种武器、26 条武器路线，支持手动瞄准或自动攻击。
- 5 张独立地图与无缝连接五种环境的「五境大远征」。探索遗物、地标事件与沿途遭遇，搭配技能挑战首领。
- 支持电脑与手机、迷雾探索与完整地形显示；下载完整资源后可离线游玩。

准备页选择人物、武器、地图和攻击模式，查看该地图的首领、招式和通关目标，再点击「踏入荒野」。首轮围猎约在 31 秒到来，独立地图约 2 分钟后迎战首领；五境大远征需完成各区地标并领取奖励，再靠近路标唤醒守卫，击败全部五位通关。首次交互后开启声音；右上角「声音设置」可切换音效版本、分别调整音乐与音效音量，并保存在当前浏览器。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 转动视角 | 第一人称直接移动鼠标；第三人称右键拖动或锁定鼠标 | 拖动画面空白处，或拖动右侧攻击键 |
| 瞄准与攻击 | 画面中心准星，按住左键 | 自动瞄准时按住攻击键；手动时中心准星瞄准 |
| 第一 / 第三人称 | V / 顶部「视角」；第三人称滚轮调整距离 | 顶部「视角」 |
| 闪避 / 角色能力 | Shift / 空格 | 闪避按钮 |
| 暂停与继续 | Esc（释放鼠标）/ 暂停按钮 | 暂停按钮 |
| 探索地图 | M / 点击小地图 | 点击小地图 |

升级次数会暂存到「选择成长」按钮，可主动点开，也可按 Esc 从暂停菜单选择成长；自动选卡等待战斗空档，两轮至少间隔 18 秒。点「稍后选择」保留本轮卡片和次数。新介绍仅短暂显示，已经展示的内容跨局记住；完整图鉴仍可从右上角「?」查看。

v115 为自由视角首个可玩版本：可在同一局切换第一 / 第三人称，移动与闪避跟随镜头水平朝向，第三人称镜头遇到树石会缩近。普通枪弹与法术弹具备上下射向，地面毒雾、符书、近战与回旋武器保留各自的地面规则。第一人称现已显示双手、前臂和各角色袖口，武器有独立取景与出手、回收动作；采用程序化持握，尚非专门制作的完整手臂动画资产。地图仍以原有平面碰撞行走，暂不含攀爬、跳跃平台或建筑室内。

第一人称进入战斗时尝试锁定鼠标，直接移动即可转向，不必按住右键；Esc 释放鼠标并暂停，选「继续远征」返回。浏览器拒绝锁定时，鼠标在画面内移动仍可转向，但受窗口边缘限制，可点「锁定鼠标」重试。

电脑自动攻击模式会寻找视野内附近目标并出手；手机默认自动瞄准，需按住右侧攻击键才攻击，松手停止，也可选择手动瞄准。手机顶部「按键」可调整移动、攻击与闪避键大小（75%–135%），选择自动保存。新物种与事件提示在手机顶部显示，点提示可暂停阅读完整介绍。手机横屏优先，也支持竖屏；电脑和手机均可在探索地图中查看已发现地点、设置路标。

## 离线游玩

1. 首次联网打开游戏，展开右上角「下载 / 离线」，下载完整离线资源。
2. 等待资源准备好后，可添加到桌面或收藏游戏地址；之后使用同一浏览器，即可断网重新打开。
3. 已下载离线版会在联网打开时自动检查更新，下载完成后在准备页主动启用，不打断正在进行的对局。资源缺失或下载中断可重试修复。

首页标题旁会显示版本号。若旧收藏一直打开旧版，请使用上方「开始游戏」新入口，无需清除网站数据。

游戏记录和离线资源保存在当前浏览器；清除网站数据会一并清除。安装入口取决于浏览器支持，未安装时仍可从已保存资源的浏览器离线打开。运行需要支持 WebGL 的现代浏览器。

## 本地运行与开发

在本目录启动静态服务器：

```sh
python -m http.server 8897
```

打开 [本地游戏](http://localhost:8897/)。不能直接双击 HTML 文件运行模块。Three.js 已包含在仓库中，运行时无需第三方 CDN；自动检查使用 Node.js，无需 `npm install`。

修改游戏资源后，重建离线清单并检查：

```sh
npm run offline:build
npm run offline:check
npm test
```

`tests/browser-*.cjs` 是可选的 Playwright 浏览器检查，可通过 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE`、`TEST_URL` 指定已有环境；[声音试听页](tests/audio-listening.html)可通过同一静态服务器打开。自动检查和手机尺寸模拟不等同于长局平衡、主观听感或安卓真机与低端 GPU 验证。
