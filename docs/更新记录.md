## v19 · 技能去硬边圆圈

移除火、冰、雷、暗影技能及受击、翻滚、升级的硬边扩散圆圈：以爆燃、余烬、非规则冰晶、冰裂、电弧、卷吸暗雾和上升光屑表现技能。暗影牵引的视觉脉冲适度减少，手机粒子预算保持不变。

危险范围改用柔边半透明地面预警，保留原来的攻击半径和伤害时机；狼和蘑菇的扑击落点改用短爪痕，首领冲撞用方向箭头带标示。毒雾区域持续轻微翻涌，祭坛及补给的常驻线圈改为靠近时的微光。战场说明同步更新。

## v18 · 圆润影客与专属武器

影裔调整为约三头身的大兜帽、宽胸腹、短手短腿比例。前进、倒退、侧移按移动方向调整步态，身体轻微起伏，披风跟随；掌心推咒、侧身掷镰和托书施法分别制作上身动作。

三种专属主武器：噬影掌保留三击刻印；回魂影镰默认投出单枚弧刃并折返，升级可分裂或增强穿透；悬影魔典在瞄准方向的目标脚下预告裂口，0.28 秒后爆发，升级扩大范围或在 0.32 秒后再次爆发。三者有独立外观、攻击声音与成长路线。魔典不与霜影共用暗法杖。

## v17 · 影裔形象与动作重做

影裔改为适度 Q 版的兜帽刺客：保留稍大的兜帽，胸背、腰腹与四肢更厚实，重新调整腿部和手臂比例，并将人物整体缩小。用连贯的衣袍曲面、内凹面罩和青蓝色三道裂光取代堆叠几何块。手肘、膝盖和脚踝分别运动；披风和衣摆会在奔跑、转身时弯曲跟随，影球、幽刃和法杖使用不同的上肢出招姿势。

## v16 · 影裔

新增可选的低多边形暗影角色「影裔」，比原来的两名人物更矮，使用兜帽、符纹面罩和碎片短披风来贴近怪物的美术风格。专属影脉法球三次命中会引爆刻印；幽刃回旋可升级为群刃或折返；也可选择原有夜幕法杖。影裔有独立的暗幕、缚影、裂隙技能与短距影步，以及对应的紫黑色特效和音效。原有两位角色及其技能池保留。电脑、手机横屏和竖屏均可选择游玩。

## v15 · 怪物动作衔接

狼与菌怪的扑击先加速、再收力，落地后有短暂缓冲；狼和石怪蓄力时压低重心，施法怪移动时增加独立的身体与法杖摆动。怪物绕开障碍时朝实际行进方向转身。首领不再原地空踏步，转向改为渐进过渡。攻击范围、伤害和原有预警保持不变。

## v14 · 游玩流程修复与元素特效

首领生成会寻找无遮挡位置，避免出现在树和石柱里；普通怪物达到数量上限时，补给点和祭坛仍会召出守卫，击败后才能领取奖励。三张地图的天气材质会在重开时复用。火焰增加爆心和余烬扩散，冰晶环增加不规则裂纹，雷击增加落点冲击，暗能增加柔边暗影与旋入碎片；危险范围标记仍保持清晰。新增三张地图的三分钟战斗逻辑模拟，以及资源点、首领生成、胜负结算与重开检查。

## v13 · 天气漂移与六武器动作

林地萤光、雪花和赤烬地飘灰现在留在地图坐标中随机漂移，并随时间消散、在附近不同位置重新出现；移动人物不会拖着同一批粒子走。短弩保留上弦动作；步枪增加持枪后坐，霰弹枪增加前握把抽拉，飞镖增加挥臂投掷，火杖和暗杖分别采用上举施法与横扫动作。动作随出招与装填播放，结束后回到瞄准或移动姿势。

## v12 · 怪物动作与活跃场景

林地出现漂浮萤光，雪地有风雪，赤烬地有飘灰；这些景物围绕玩家更新，控制绘制开销。蘑菇帽上的斑点随攻击一起摆动，狼的尾巴、下颚和祭司杖头会随动作变化，移动中的敌人还会扬起对应地表的尘雪。赤烬地的部分地块改为周期喷发的地脉，先亮起警戒圈，再对圈内玩家和怪物造成伤害；喷发区不会被石柱遮住，战场说明也写明了作用。

## v11 · 手动与自动攻击模式

准备界面可选择「手动瞄准」或「自动攻击」，暂停时也能切换，选择会保存在当前浏览器。手动模式保持鼠标或手机右摇杆瞄准、按住射击；自动模式在武器射程内寻找无遮挡的最近怪物，转向后按原武器射速攻击，无目标时停止。手机自动模式隐藏右侧射击摇杆，移动和闪避继续可用。

## v10 · 怪物攻击与战场说明

蘑菇会蓄力弹跳，林地狼绕侧后猛扑，石怪举臂震地，吐毒怪投出持续毒雾，祭司会治疗受伤同伴或施放减速咒。怪物增加蓄力、扑击和挥杖动作。首次遇见新物种会出现攻击提示，右上角「？」可在暂停状态下查看所有怪物和地面圈的含义；手机横屏也能打开。

## v9 · 攻击动作稳定性

修复短弩连续攻击时手臂姿势逐帧累积而突然跳动的问题。快速改变瞄准方向时，持弩动作跟随人物平滑转身，转到射击方向后再放箭；停火后副手更自然地放下。保留主动瞄准、按住攻击和手机双摇杆操作。

## v8 · 自由瞄准与短弩拉弦

六种主武器改为主动射击：电脑用鼠标指向目标，按住左键持续攻击；手机用左摇杆移动、右摇杆拖动定向并持续攻击。松开即停。怪物不再触发主武器自动索敌，火、冰、雷的独立升级仍会自动释放。短弩抬到胸前，装填时副手后拉弩弦，箭矢随放弦出现，放弦后复位。

## v7 · 霜影短弩与战斗反馈

霜影的初始武器改为夜翎短弩，保持飞镖与暗法杖；短弩连续三箭命中同一怪物会造成短暂击退和停顿，首领只承受额外伤害。箭矢、命中碎片、上弦与穿刺声分别制作；兽群和首领来袭时加入音乐提示，并强化高压战斗节奏。

## v6 · 场景细节与瞬移反馈

林地、雪地和灰烬地改用更柔和的地表纹理与不规则小径、减速区域；树冠和地面植被的形状与分布增加变化。霜影瞬移时不再出现脚下圆环，保留暗色碎片和音效。人物仍是原来的霜影与林地游侠。

## v5 · 人物比例、动态表现与加载

- 两名角色统一缩短约 9%，头部放大 8%，保留猎手装束和原有模型细节；步频随缩短后的步幅校正。六种武器增加力度不同的身体后坐或施法前倾，继续校正枪口瞄准方向。
- 狼的四肢独立迈步，石怪摆臂与沉重步态，蘑菇弹跳、压缩回弹，施法怪缓慢浮动。敌人有蓄力后倾、出招前扑和受击回弹，替代原来的整身闪烁。林地/雪地图树冠轻微随风摆动，暂停冻结新增动画。
- 七条实际使用的动作提前转换，取消每次打开时下载整套 7.6 MB 动作库并现场转换。几何资源无损压缩，人物相关资源从 16.2 MB 降到 5.2 MB，约减少 68%；网页代码和 Three.js 不包含在这个数字中。缓存成功后再次进入不需要重新请求人物资源，首次速度仍取决于网络和设备。
- `node scripts/pack-characters.mjs` 可从仓库中的原资产重建带内容哈希的压缩资源及清单。原始模型、贴图和许可保留；无解压接口时回退原模型与已转换的 JSON 动作，无存储权限时回退普通网络请求。
- `tests/packed-assets.test.js` 检查解压后的模型几何逐字节一致和动作包；`tests/browser-loading.cjs` 检查缓存复用、禁用缓存、旧浏览器回退及下载失败重试。浏览器回归覆盖电脑、手机横竖屏；尚未在安卓真机上测量帧率。

## v4 · 武器路线与技能表现

## v3 · 移动和命中反馈

- 修复无目标时跑步朝向不跟随输入的问题，人物按最短方向渐进转身；射击朝向在攻击间隔内保持，避免每次发射都来回扭身。
- 按实际位移调整步频，慢走/跑步连续混合，脚步周期同步；起停有短过渡，顶住障碍物会停止迈步。增加转弯侧倾、侧向步态调整和后退步态混合；后退目前基于现有跑步动作反向播放，并非独立制作的完整后退动画。
- 无方向输入时，闪避跟随人物当前朝向。
- 普通命中改为 0.16 秒的小碎屑，取消普通击杀及火/暗普通攻击的光圈。保留范围技能和危险区域提示，伤害数值不变。
- `tests/browser-locomotion.cjs` 检查无目标朝向、反向转身、停步、碰撞停步、闪避方向，以及普通命中/击杀不再生成光圈。

## v2 · 声音、角色与经验反馈

### 可玩内容

- 三位可选角色：林地游侠（翻滚）、霜影（白发黑面罩、瞬移）及原创低多边形影裔（影步）。前两位使用 Quaternius CC0 人物和动画资源并作外观、动作适配；影裔为程序建模。
- 九种武器：连发枪、霰弹枪、火法杖、短弩、穿透飞镖、暗法杖、噬影掌、回魂影镰、悬影魔典。主动瞄准攻击。
- 三种环境：翡翠幽林、霜月峡谷、赤烬荒原。地形会减速，树木有实体碰撞；随机布景、不同植被与地表。
- 游侠与霜影可升级陨火、冰晶环、连锁落雷；影裔可升级暗幕、缚影、裂隙。经验连升会逐次提供选择。
- 五种普通敌人、怪群包围、远程落点预警、支援治疗。
- 补给和祭坛需要清理守卫，分别给予治疗/吸引经验与技能。三分钟后出现首领，冲撞、半血三重裂地及攻击后反击窗口；击败首领完成远征。
- 暂停、继续、确认结束、胜负结算、重开、声音开关、小地图与低血量提示。

### 操作

手动模式：电脑 WASD / 方向键移动，鼠标指向并按住左键持续攻击，Shift / 空格闪避，Esc 暂停；手机左摇杆移动、右摇杆拖动瞄准并持续攻击、闪避键闪避。自动模式保留移动和闪避，武器会自行瞄准并攻击附近怪物。横屏优先，也支持竖屏；切到其他应用自动暂停。

通过网页初次打开需联网；在「下载 / 离线」保存完整资源后，可以离线重新打开。3D 渲染需要支持 WebGL 的浏览器。

### 美术与声音

游侠与霜影使用 Quaternius 发布的 CC0 模型、服装、发型及骨骼动作，本项目调整肤色、服装轮廓、面罩、披风、武器握持及动画混合。来源与许可见 [THIRD_PARTY_ASSETS.md](../THIRD_PARTY_ASSETS.md)。影裔、场景、敌人、武器和特效为程序构建的简洁几何风格。影裔借鉴暗影刺客的设计方向，并未使用其他游戏的角色资产。

当前配乐使用本地 CC0 录音与 Web Audio 合成的组合：森林、雪地、赤烬、海岸和高压／首领战使用第三方录音，沙地及录音加载／失败时使用程序化配乐。枪械爆发、火焰轰鸣、冰晶碎裂、电弧、瞬移、命中和升级继续使用本地合成音效。首次点击开始或开启声音后播放，可分别调节音乐/音效音量，设置在本机保存。录音来源与处理方式见 [THIRD_PARTY_ASSETS.md](../THIRD_PARTY_ASSETS.md)。

人物模型、贴图和预处理动作加载时会显示进度，加载失败可以重试。人物资源尽可能缓存在浏览器中，容量不足或禁止存储时仍可联网运行。旧浏览器没有 gzip 解压接口时使用未压缩兼容资源。资源随仓库部署，不依赖运行时第三方 CDN；完整离线包还包含网页、地图与约 7.5 MB 的录音配乐，需要通过「下载 / 离线」明确保存。

### 本地开发

使用 HTTP 静态服务器运行目录，例如 `python -m http.server 8897`，然后打开 `http://localhost:8897/`。不能通过直接双击 HTML 文件加载模块。

`npm test` 执行纯规则/地图/模型检查，无需 npm install。Three.js 0.180.0 已固定在 vendor，保留其 MIT LICENSE；运行时不依赖 CDN。

### 验证与边界

规则与资源自动检查包含 90 张地图的出生与探索点通行。浏览器测试覆盖武器、动作、电脑及手机横竖屏操作，也验证移动、闪避、暂停、连升选择、技能、胜利、失败与重开。测试含主动触发首领和伤害的流程验证，不等同于真人通关或全面平衡测试。尚未完成安卓真机和低端 GPU 测试。
